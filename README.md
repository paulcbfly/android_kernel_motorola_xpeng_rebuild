# android_kernel_motorola_xpeng_rebuild

Rebuild workspace for the Motorola xpeng (Edge S30 / G200) 5.4.302 kernel.

Seeded from the working configuration published as the r7 release
(upstream commit `b3ecce7eb4fc` of `android_kernel_motorola_xpeng`):
5.4.302-moto + SUSFS v2.2 + ReSukiSU, no optional modules.

The full source tree is provided as a tarball asset on the `r7-snapshot`
release, then imported as the initial branch commit.
